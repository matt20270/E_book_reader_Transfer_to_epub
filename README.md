# X4 Pro Reader Studio (웹 v0.2.0)

설치 없이 브라우저에서 쓰는 전자책 변환·TXT 정리 사이트입니다. 서버가 없고 **파일은 기기 밖으로 나가지 않습니다.**

## 할 수 있는 일
- **PDF → EPUB**: 글자가 있는 PDF는 글자를 그대로 가져오고, 스캔한 쪽은 브라우저 안에서 글자 인식(OCR, 한국어+영어)을 합니다. 쪽 번호·머리말 자동 제거, 제목으로 목차 만들기, 쪽마다 "글 / 쪽 이미지 / 글+이미지 / 제외" 선택, 인식이 불확실한 단어 노란색 표시 후 직접 수정.
- **TXT 정리**: 줄바꿈이 엉킨 TXT를 문단으로 복원 (UTF-8/CP949 등 저장).

## GitHub Pages에 올리는 방법 (터미널 필요 없음)
1. GitHub에 로그인하고 **New repository**로 새 저장소를 만듭니다 (Public, 이름 예: `x4-reader`).
2. 저장소 화면에서 **uploading an existing file**을 누릅니다.
3. 이 ZIP을 풀고, **폴더 안으로 들어가서** 전체 선택(Cmd+A)한 뒤 끌어다 놓습니다. (폴더째 끌면 안 됩니다. 숨김 파일 `.gitignore`도 올리려면 Finder에서 Cmd+Shift+. 로 숨김 파일을 먼저 표시하세요.) 파일은 91개라 한 번에 올라갑니다 (GitHub 웹 업로드는 한 번에 100개까지).
4. 아래쪽 **Commit changes**를 누릅니다.
5. **Settings → Pages → Branch: main / (root) → Save**. 1~2분 뒤 주소가 나타납니다.

## 사용 순서 (PDF → EPUB)
1. PDF를 선택하고 옵션을 정한 뒤 **변환 시작**을 누릅니다. 진행률과 남은 시간이 표시됩니다.
2. **검토 및 수정** 화면에서 쪽을 넘기며 확인합니다. 왼쪽은 원본 쪽, 오른쪽은 인식된 글입니다. 노란 글자는 인식이 불확실한 단어입니다. "다음 확인 필요 쪽" 버튼으로 바로 이동할 수 있습니다.
3. 책 제목·저자를 입력하고 **EPUB 만들기**를 누릅니다.

## 알아 두세요 (한계)
- **OCR 정확도는 원본에 크게 좌우됩니다.** 흰 바탕의 깨끗한 인쇄 글자는 잘 읽지만, 사진 위에 얹힌 기울어진 글자는 많이 틀립니다. 그런 쪽은 "쪽 이미지"로 두세요. ("OCR 신뢰도가 낮은 쪽은 자동으로 쪽 이미지로" 옵션을 켤 수 있습니다.)
- 2단 편집 논문, 수식, 표는 글로 정확히 옮기지 못합니다. 그런 쪽은 "쪽 이미지"를 권합니다.
- 쪽 이미지는 480×800 화면에서 작게 보입니다. 작은 글자는 "960×1600" 옵션을 쓰세요.
- PDF 용량 상한: 기본 50MB, 50~150MB는 경고 후 허용, 150MB 초과는 열 수 없습니다. 최대 1500쪽.
- 한국어 문자 매핑(cmaps)만 내장했습니다. 글꼴이 PDF에 들어 있지 않은 일본어·중국어 PDF는 글자 추출이 깨질 수 있습니다.
- 아직 **실제 X4 Pro 기기에서의 확인은 하지 않았습니다.** (Chromium 브라우저에서만 자동 시험했습니다.)
- 휴대폰은 메모리가 적어 큰 PDF에서 느리거나 멈출 수 있습니다. 큰 PDF는 PC/맥북을 권합니다.

## 보안 설계
- `connect-src 'none'`: 브라우저가 외부 서버로 어떤 데이터도 보내지 못합니다. CSP는 `default-src 'self'; script-src 'self'; style-src 'self'; ...` 그대로이며 **완화하지 않았습니다.**
- 모든 라이브러리(pdf.js, Tesseract.js, JSZip, 한·영 인식 데이터)는 `vendor/`에 내장되어 있고 외부 CDN을 쓰지 않습니다.
- PDF·OCR에서 나온 글은 `textContent`/`createTextNode`로만 화면에 넣습니다 (`innerHTML` 사용 없음). EPUB에는 XML 특수문자를 이스케이프하고 금지 문자를 제거해 넣습니다.
- 파일 크기·쪽수·쪽 한 장의 픽셀 수 상한, 다운로드 파일명 정제, `.gitignore` 적용.

## 개발자용
```bash
node --test tests/*.test.js     # 24개 자동 시험 (Node 22 이상)
```
구조: `js/layout.js`(문단·제목·머리말 처리), `js/epub.js`(EPUB 생성), `js/pdf.js`·`js/ocr.js`(라이브러리 래퍼), `js/convert.js`(변환 화면), `js/txt.js`(TXT 엔진), `js/limits.js`(상한값).
